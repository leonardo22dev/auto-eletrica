# Mizuho OS — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar um webapp que substitui o talão de papel da Auto Elétrica Mizuho II — preencher OS no celular, gerar o PDF replicando o talão, e manter histórico pesquisável por cliente e placa.

**Architecture:** SPA em React servida estática, falando direto com o Postgres do Supabase via `supabase-js`, protegida por RLS. Regras de negócio que não podem divergir (total da OS, numeração, devolução de número) ficam no banco, em trigger e função. O PDF é gerado no navegador, vetorial, por um módulo isolado que não conhece nem Supabase nem roteamento.

**Tech Stack:** Vite · React 19 · Tailwind 4 · react-router-dom 7 · @supabase/supabase-js · @react-pdf/renderer · Vitest · oxlint

**Spec:** `docs/superpowers/specs/2026-10-13-mizuho-os-design.md`

**Maquete visual aprovada:** `docs/maquete.html` — é a fonte da marcação e das classes das telas. Abra no navegador antes de começar qualquer tarefa de UI.

## Global Constraints

- Idioma de toda a interface, mensagens e nomes de código: **português do Brasil**.
- Dinheiro é **inteiro em centavos** em toda a aplicação e no banco. Nenhum valor monetário trafega como float.
- Placa é gravada e consultada **normalizada**: maiúscula, sem hífen, sem espaço. Aceita antiga (`ABC1234`) e Mercosul (`ABC1D23`).
- Datas puras (`data_abertura`, `data_conclusao`) são `date` no banco e string `YYYY-MM-DD` no JS. **Nunca** usar `new Date('YYYY-MM-DD')` para formatá-las — isso interpreta como UTC e devolve o dia anterior no fuso de Brasília.
- Garantia padrão: **3 meses**, lida de `configuracoes.garantia_meses`, nunca constante no código.
- Tokens de cor: `--red #CC2E1E` · `--red-dark #9B1F12` · `--ink #141414` · `--bg #F6F4F2` · `--paper #FFFFFF` · `--line #E4E1DE`.
- Status: âmbar `#B45309`/`#FEF3C7` orçamento · azul `#1D4ED8`/`#DBEAFE` aprovada · verde `#15803D`/`#DCFCE7` finalizada · cinza cancelada.
- Tipografia: `Source Serif 4` na marca e no PDF; `Archivo` na interface.
- Alvo de toque mínimo **48px** em qualquer controle tocável.
- A chave `service_role` do Supabase **nunca** entra no código do front. Só a `anon`.
- Commits em português, no imperativo.

## Review Focus

Cinco classes de entrada que o spec pressupõe e que quebram na mão do usuário se ninguém testar. Cada linha tem o teste já alocado na tarefa dona do código.

1. **Data `YYYY-MM-DD` formatada via `new Date()`** devolve o dia anterior em UTC-3 — uma OS concluída em 12/08 imprime 11/08 no PDF. → Tarefa 2.
2. **Garantia que cai em mês mais curto**: 31/01 + 3 meses precisa dar 30/04, não 01/05. → Tarefa 2.
3. **Quantidade fracionária** (0,5 litro de fluido) multiplicada por centavos precisa arredondar para inteiro, nunca produzir `38000.000000001`. → Tarefa 1.
4. **Telefone em formatos variados** — `(11) 98888-7777`, `11988887777`, `+55 11 98888-7777` — todos precisam gerar o mesmo link `wa.me`. → Tarefa 13.
5. **OS sem nenhum item**: total 0, PDF válido com as 18 linhas em branco, sem travar a tela. → Tarefas 1 e 12.

```js
const formatadorBRL = new Intl.NumberFormat('pt-BR', {
  style: 'currency',
  currency: 'BRL',
})

const formatadorSimples = new Intl.NumberFormat('pt-BR', {
  minimumFractionDigits: 2,
  maximumFractionDigits: 2,
})

export function formatarBRL(centavos) {
  return formatadorBRL.format((centavos || 0) / 100).replace(/\u00A0/g, ' ')
}

export function centavosParaTexto(centavos) {
  return formatadorSimples.format((centavos || 0) / 100)
}

export function textoParaCentavos(texto) {
  if (typeof texto !== 'string') return 0
  let limpo = texto.replace(/[^\d,.-]/g, '')
  if (limpo === '') return 0
  // Com vírgula, ela é o decimal e o ponto é separador de milhar.
  // Sem vírgula, um ponto sozinho pode ser decimal.
  if (limpo.includes(',')) {
    limpo = limpo.replace(/\./g, '').replace(',', '.')
  }
  const valor = Number.parseFloat(limpo)
  if (!Number.isFinite(valor)) return 0
  return Math.round(valor * 100)
}

export function totalDoItem(quantidade, valorUnitarioCentavos) {
  const q = Number(quantidade) || 0
  const v = Number(valorUnitarioCentavos) || 0
  return Math.round(q * v)
}

export function somarCentavos(lista) {
  return (lista || []).reduce((soma, v) => soma + (Number(v) || 0), 0)
}
```

```js
const ANTIGA = /^[A-Z]{3}\d{4}$/
const MERCOSUL = /^[A-Z]{3}\d[A-Z]\d{2}$/

export function normalizarPlaca(valor) {
  if (typeof valor !== 'string') return ''
  return valor.toUpperCase().replace(/[^A-Z0-9]/g, '')
}

export function placaValida(placa) {
  const p = normalizarPlaca(placa)
  return ANTIGA.test(p) || MERCOSUL.test(p)
}

export function formatarPlaca(placa) {
  const p = normalizarPlaca(placa)
  if (ANTIGA.test(p)) return `${p.slice(0, 3)}-${p.slice(3)}`
  return p
}
```

- [ ] **Step 7: Implementar `src/lib/datas.js`**

```js
const MESES = [
  'janeiro', 'fevereiro', 'março', 'abril', 'maio', 'junho',
  'julho', 'agosto', 'setembro', 'outubro', 'novembro', 'dezembro',
]

const FUSO = 'America/Sao_Paulo'

// Datas puras são tratadas como texto, nunca como Date.
// Date interpreta 'YYYY-MM-DD' como UTC e devolve o dia anterior aqui.
function partes(iso) {
  if (typeof iso !== 'string') return null
  const m = iso.match(/^(\d{4})-(\d{2})-(\d{2})/)
  if (!m) return null
  return { ano: m[1], mes: m[2], dia: m[3] }
}

export function hojeISO() {
  const agora = new Date()
  const fmt = new Intl.DateTimeFormat('en-CA', {
    timeZone: FUSO, year: 'numeric', month: '2-digit', day: '2-digit',
  })
  return fmt.format(agora)
}

export function formatarData(iso) {
  const p = partes(iso)
  if (!p) return ''
  return `${p.dia}/${p.mes}/${p.ano}`
}

export function dataPorExtenso(iso) {
  const p = partes(iso)
  if (!p) return { dia: '', mes: '', ano: '' }
  return { dia: p.dia, mes: MESES[Number(p.mes) - 1], ano: p.ano }
}

// Timestamps, ao contrário, carregam o instante e podem virar Date.
export function formatarDataHora(timestamp) {
  if (!timestamp) return ''
  const d = new Date(timestamp)
  if (Number.isNaN(d.getTime())) return ''
  const fmt = new Intl.DateTimeFormat('pt-BR', {
    timeZone: FUSO,
    day: '2-digit', month: '2-digit', year: 'numeric',
    hour: '2-digit', minute: '2-digit', hour12: false,
  })
  const partesFmt = Object.fromEntries(
    fmt.formatToParts(d).map((p) => [p.type, p.value]),
  )
  return `${partesFmt.day}/${partesFmt.month}/${partesFmt.year} às ${partesFmt.hour}:${partesFmt.minute}`
}
```

```js
function ultimoDiaDoMes(ano, mes) {
  // mes é 1-12. Dia 0 do mês seguinte é o último dia deste.
  return new Date(Date.UTC(ano, mes, 0)).getUTCDate()
}

export function vencimentoGarantia(dataConclusaoISO, meses) {
  if (typeof dataConclusaoISO !== 'string') return null
  const m = dataConclusaoISO.match(/^(\d{4})-(\d{2})-(\d{2})/)
  if (!m) return null

  const qtd = Number(meses) || 0
  const ano = Number(m[1])
  const mes = Number(m[2])
  const dia = Number(m[3])

  const totalMeses = (ano * 12) + (mes - 1) + qtd
  const anoFinal = Math.floor(totalMeses / 12)
  const mesFinal = (totalMeses % 12) + 1
  const diaFinal = Math.min(dia, ultimoDiaDoMes(anoFinal, mesFinal))

  return [
    String(anoFinal).padStart(4, '0'),
    String(mesFinal).padStart(2, '0'),
    String(diaFinal).padStart(2, '0'),
  ].join('-')
}

export function garantiaVigente(vencimentoISO, referenciaISO) {
  if (!vencimentoISO || !referenciaISO) return false
  // Strings YYYY-MM-DD comparam corretamente em ordem lexicográfica.
  return referenciaISO <= vencimentoISO
}

  [STATUS.FINALIZADA]: [STATUS.CANCELADA],

-- O total nunca é responsabilidade do front: o banco recalcula sozinho.
create or replace function recalcular_total_os() returns trigger
language plpgsql security definer set search_path = public, pg_temp as $$
declare alvo uuid;
begin
  alvo := coalesce(new.os_id, old.os_id);
  update ordens_servico
     set total_centavos = coalesce(
           (select sum(valor_total_centavos) from os_itens where os_id = alvo), 0),
         atualizado_em = now()
   where id = alvo;
  return null;
end $$;

create trigger os_itens_recalcula_total
after insert or update or delete on os_itens
for each row execute function recalcular_total_os();

create or replace function tocar_atualizado_em() returns trigger
language plpgsql as $$
begin
  new.atualizado_em := now();
  return new;
end $$;

create trigger clientes_toca_atualizado before update on clientes
  for each row execute function tocar_atualizado_em();
create trigger veiculos_toca_atualizado before update on veiculos
  for each row execute function tocar_atualizado_em();
create trigger ordens_toca_atualizado before update on ordens_servico
  for each row execute function tocar_atualizado_em();

-- Cancela a OS e, se ela for a última emitida, devolve o número à sequence.
-- Devolve true quando o número foi devolvido.
create or replace function cancelar_os(p_os_id uuid) returns boolean
language plpgsql security invoker set search_path = public, pg_temp as $$
declare
  v_numero bigint;
  v_status text;
  v_seq    bigint;
begin
  select numero, status into v_numero, v_status
    from ordens_servico where id = p_os_id for update;

  if not found then
    raise exception 'OS % não encontrada', p_os_id;
  end if;
  if v_status = 'cancelada' then
    return false;
  end if;

  update ordens_servico set status = 'cancelada' where id = p_os_id;

  v_seq := pg_sequence_last_value('os_numero_seq'::regclass);

  -- Só devolve se esta OS for de fato a ponta da numeração. Se outra pessoa
  -- emitiu uma OS no intervalo, a sequence já avançou, a comparação falha e
  -- nada é devolvido — a condição se protege sozinha contra concorrência.
  if v_numero is not null
     and v_seq = v_numero
     and not exists (select 1 from ordens_servico
                      where numero is not null and numero > v_numero) then
    update ordens_servico set numero = null where id = p_os_id;
    if v_numero <= 1 then
      perform setval('os_numero_seq', 1, false);
    else
      perform setval('os_numero_seq', v_numero - 1, true);
    end if;
    return true;
  end if;

  return false;
end $$;

-- Usada na tela de Configurações para continuar de onde o talão parou.
create or replace function definir_proximo_numero(p_numero bigint) returns void
language plpgsql security invoker set search_path = public, pg_temp as $$
begin
  if p_numero < 1 then
    raise exception 'O próximo número precisa ser maior que zero';
  end if;
  if exists (select 1 from ordens_servico
              where numero is not null and numero >= p_numero) then
    raise exception 'Já existe OS com número maior ou igual a %', p_numero;
  end if;
  perform setval('os_numero_seq', p_numero, false);
end $$;
```

    const { data: sub } = supabase.auth.onAuthStateChange((_evento, nova) => {
      setSessao(nova)
    })

  }, [])

      email: email.trim(),
      password: senha,
    })

  }

  async function sair() {
    await supabase.auth.signOut()
  }

  return <Ctx.Provider value={valor}>{children}</Ctx.Provider>

export async function listarOrdens({

  let q = supabase.from('ordens_servico').select(CAMPOS_LISTA)

}

export async function buscarOrdem(id) {
  const { data, error } = await supabase
    .from('ordens_servico')
    .select('*, itens:os_itens(*)')
    .eq('id', id).single()
  if (error) throw new Error('Ordem de serviço não encontrada.')
  data.itens.sort((a, b) => a.posicao - b.posicao)
  return data
}

export async function ultimaOrdemDoVeiculo(veiculoId) {
  const { data, error } = await supabase
    .from('ordens_servico')
    .select(CAMPOS_LISTA)
    .eq('veiculo_id', veiculoId)
    .eq('status', STATUS.FINALIZADA)
    .order('data_conclusao', { ascending: false, nullsFirst: false })
    .limit(1).maybeSingle()
  if (error) throw new Error('Não foi possível consultar o histórico do veículo.')
  return data
}

function linhasDeItens(osId, itens) {
  return itens
    .filter((i) => String(i.descricao || '').trim() !== '')
    .map((i, indice) => ({
      os_id: osId,
      posicao: indice + 1,
      quantidade: Number(i.quantidade) || 1,
      descricao: String(i.descricao).trim(),
      valor_unitario_centavos: Number(i.valor_unitario_centavos) || 0,
      valor_total_centavos: totalDoItem(i.quantidade, i.valor_unitario_centavos),
    }))
}

export async function criarOrdem({ cliente, veiculo, itens = [],
                                   status = STATUS.ORCAMENTO, observacoes = '' }) {
  const { data: sessao } = await supabase.auth.getUser()
  const { data: os, error } = await supabase.from('ordens_servico').insert({
    status,
    cliente_id: cliente.id,
    veiculo_id: veiculo.id,
    cliente_nome: cliente.nome,
    cliente_telefone: cliente.telefone,
    veiculo_descricao: veiculo.descricao,
    veiculo_placa: normalizarPlaca(veiculo.placa),
    observacoes,
    data_aprovacao: status === STATUS.ORCAMENTO ? null : new Date().toISOString(),
    criado_por: sessao?.user?.id ?? null,
  }).select().single()
  if (error) throw new Error('Não foi possível criar a ordem de serviço.')

  const linhas = linhasDeItens(os.id, itens)
  if (linhas.length) {
    const { error: erroItens } = await supabase.from('os_itens').insert(linhas)
    if (erroItens) throw new Error('A OS foi criada, mas os itens não foram salvos.')
  }
  return buscarOrdem(os.id)
}

export async function atualizarItens(osId, itens) {
  const { error: erroApaga } = await supabase
    .from('os_itens').delete().eq('os_id', osId)
  if (erroApaga) throw new Error('Não foi possível atualizar os itens.')

  const linhas = linhasDeItens(osId, itens)
  if (linhas.length) {
    const { error } = await supabase.from('os_itens').insert(linhas)
    if (error) throw new Error('Não foi possível salvar os itens.')
  }
}

export async function mudarStatus(osId, novoStatus) {
  const atual = await buscarOrdem(osId)
  if (!podeTransicionar(atual.status, novoStatus)) {
    throw new Error(`Não é possível ir de ${atual.status} para ${novoStatus}.`)
  }
  if (novoStatus === STATUS.CANCELADA) {
    await cancelarOrdem(osId)
    return buscarOrdem(osId)
  }

  const campos = { status: novoStatus }
  if (novoStatus === STATUS.APROVADA) campos.data_aprovacao = new Date().toISOString()
  if (novoStatus === STATUS.FINALIZADA && !atual.data_conclusao) {
    campos.data_conclusao = hojeISO()
  }

  const { error } = await supabase
    .from('ordens_servico').update(campos).eq('id', osId)
  if (error) throw new Error('Não foi possível mudar o status.')
  return buscarOrdem(osId)
}

// Devolve true quando o número foi devolvido à sequence.
export async function cancelarOrdem(osId) {
  const { data, error } = await supabase.rpc('cancelar_os', { p_os_id: osId })
  if (error) throw new Error('Não foi possível cancelar a ordem de serviço.')
  return Boolean(data)
}

  } catch {
    return null
  }
}

}

import { tituloDocumento } from '../lib/status.js'
import { dataPorExtenso } from '../lib/datas.js'
import { formatarPlaca } from '../lib/placa.js'
import { centavosParaTexto } from '../lib/dinheiro.js'

// O talão de papel tem 18 linhas fixas. Manter isso preserva o peso visual
// do documento e deixa espaço para anotação à mão na oficina.
export const LINHAS_DO_TALAO = 18

const LINHA_VAZIA = {
  quantidade: '', descricao: '', unitario: '', total: '', vazia: true,
}

function formatarQuantidade(valor) {
  const n = Number(valor) || 0
  return Number.isInteger(n)
    ? String(n)
    : String(n).replace('.', ',')
}

export function montarDadosDocumento(os, config) {
  const itens = (os.itens || []).slice().sort((a, b) => a.posicao - b.posicao)

  const preenchidas = itens.slice(0, LINHAS_DO_TALAO).map((i) => ({
    quantidade: formatarQuantidade(i.quantidade),
    descricao: i.descricao,
    unitario: centavosParaTexto(i.valor_unitario_centavos),
    total: centavosParaTexto(i.valor_total_centavos),
    vazia: false,
  }))

  const linhas = preenchidas.concat(
    Array.from(
      { length: Math.max(0, LINHAS_DO_TALAO - preenchidas.length) },
      () => ({ ...LINHA_VAZIA }),
    ),
  )

  return {
    empresa: {
      razaoSocial: config.razao_social,
      cnpj: config.cnpj,
      inscricaoEstadual: config.inscricao_estadual,
      endereco: config.endereco,
      cidadeUf: config.cidade_uf,
      telefone: config.telefone,
      email: config.email,
      servicos: config.servicos_cabecalho || [],
    },
    titulo: tituloDocumento(os.status),
    numero: os.numero == null ? '—' : String(os.numero),
    data: dataPorExtenso(os.data_conclusao || os.data_abertura),
    cliente: { nome: os.cliente_nome, telefone: os.cliente_telefone || '' },
    veiculo: {
      descricao: os.veiculo_descricao,
      placa: formatarPlaca(os.veiculo_placa),
    },
    textoGarantia: config.texto_garantia,
    linhas,
    total: centavosParaTexto(os.total_centavos),
  }
}

```js
export function somenteDigitos(tel) {
  if (typeof tel !== 'string') return ''
  return tel.replace(/\D/g, '')
}

export function telefoneWhatsApp(tel) {
  const d = somenteDigitos(tel)
  // 10 = fixo com DDD, 11 = celular com DDD.
  if (d.length === 10 || d.length === 11) return `55${d}`
  // 12 e 13 já vêm com o DDI.
  if ((d.length === 12 || d.length === 13) && d.startsWith('55')) return d
  return null
}

export function linkWhatsApp(tel, texto) {
  const numero = telefoneWhatsApp(tel)
  const query = `?text=${encodeURIComponent(texto)}`
  return numero ? `https://wa.me/${numero}${query}` : `https://wa.me/${query}`
}
```

```js
import { supabase } from '../data/supabase.js'
import { registrarPdfDaOrdem } from '../data/ordens.js'
import { gerarPdfDaOS, nomeArquivoPdf } from './gerar.js'
import { linkWhatsApp } from '../lib/telefone.js'

const BUCKET = 'os-pdfs'

export function baixarPdf(blob, nome) {
  const url = URL.createObjectURL(blob)
  const a = document.createElement('a')
  a.href = url
  a.download = nome
  document.body.appendChild(a)
  a.click()
  a.remove()
  URL.revokeObjectURL(url)
}

// O caminho carrega o uuid da OS: público, mas não adivinhável.
async function subirPdf(os, blob) {
  const caminho = `${os.id}/${nomeArquivoPdf(os)}`
  const { error } = await supabase.storage.from(BUCKET)
    .upload(caminho, blob, { contentType: 'application/pdf', upsert: true })
  if (error) throw new Error('Não foi possível enviar o PDF.')
  await registrarPdfDaOrdem(os.id, caminho)
  const { data } = supabase.storage.from(BUCKET).getPublicUrl(caminho)
  return data.publicUrl
}

function mensagem(os, config, url) {
  const titulo = os.numero == null ? 'sua ordem de serviço' : `a OS nº ${os.numero}`
  const linhas = [
    `Olá, ${os.cliente_nome}! Segue ${titulo} da ${config.razao_social}.`,
    `Veículo: ${os.veiculo_descricao} — ${os.veiculo_placa}`,
  ]
  if (url) linhas.push(url)
  return linhas.join('\n')
}

// No celular, a Web Share API entrega o arquivo direto ao WhatsApp.
// No desktop isso não existe: o navegador não anexa arquivo no WhatsApp Web,
// então o PDF sobe para o Storage e vai o link.
export async function enviarOsPorWhatsApp({ os, config }) {
  const blob = await gerarPdfDaOS(os, config)
  const nome = nomeArquivoPdf(os)
  const arquivo = new File([blob], nome, { type: 'application/pdf' })

  if (navigator.canShare?.({ files: [arquivo] })) {
    try {
      await navigator.share({
        files: [arquivo],
        title: nome,
        text: mensagem(os, config, null),
      })
      return { via: 'compartilhamento' }
    } catch (erro) {
      if (erro?.name === 'AbortError') return { via: 'cancelado' }
      // Qualquer outra falha cai no caminho do link, abaixo.
    }
  }

  try {
    const url = await subirPdf(os, blob)
    window.open(linkWhatsApp(os.cliente_telefone, mensagem(os, config, url)), '_blank')
    return { via: 'link', url }
  } catch {
    // Sem rede para subir, ao menos entrega o arquivo na mão do dono.
    baixarPdf(blob, nome)
    return { via: 'download' }
  }
}
```
